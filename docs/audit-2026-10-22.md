## 1. Security

A sweep of the 48 commits since 2026-10-20, six reviewers in two waves, each
finding checked on both stacks before it was fixed:
`docs/security-review-2026-10-22.md`. Fifteen findings: one High, three
Medium and six Low fixed and pinned, one not reproduced, four named (three
register rows, one accepted). The High: a sign-in cookie with no nonce, sent
beside another account's application password, made a REST request run as
the cookie's user; the reference treats that request as nobody. All 91
findings of every sweep since August are fixed and each is pinned by a check
(`tests/tools/scorecard.php`).
