## LegacyPluralForms

`final class Minn\I18n\LegacyPluralForms` · `public/minn/src/Minn/I18n/LegacyPluralForms.php`

The plural expression reader the old POMO library carries (Plural_Forms),
kept apart from PluralExpression because plugins see its quirks: it reads
only n, whole numbers, parentheses, % and the comparisons, && and ||, and
the ternary, skipping spaces and tabs alone. It turns the expression into
postfix tokens once (operators of equal strength group to the left, the
ternary to the right) and runs them on a stack per number: an operand the
stack lacks is null, == and != compare strictly, values stay as PHP left
them until the answer is cast to an integer, and % is PHP's own, so a zero
divisor throws. Every refusal is an Exception with the reference's words
(probe translation-files).

- const `OP_CHARS` = `'|&><!=%?:'`
- const `LEVELS` = `array (   0 =>    array (     0 => '(',     1 => ')',   ),   1 =>    array (     0 => '?:',     1 => '?',   ),   2 =>    array (     0 => '||',   ),   3 =>    array (     0 => '&&',   ),   4 =>    array (     0 => '==',     1 => '!=',   ),   5 =>    array (     0 => '<',     1 => '<=',     2 => '>',     3 => '>=',   ),   6 =>    array (     0 => '%',   ), )` — The operators by how loosely they bind, loosest first; the parentheses below everything.

### static `parse(string $expression): array`

The expression as postfix tokens: ['var'], ['value', int] or ['op', string].

- `@return list<array{0: string, 1?: int|string}>`

### static `execute(array $tokens, int $n): int`

The value of postfix tokens for one number.

- `@param list<array{0: string, 1?: int|string}> $tokens`

## MoFile

`final class Minn\I18n\MoFile` · `public/minn/src/Minn/I18n/MoFile.php`

The GNU gettext binary catalog (.mo), read and written. The file opens
with a magic number that also says its byte order, then a revision, the
message count, and the offsets of two tables of (length, offset) pairs:
the originals, then the translations. The entry with an empty original
carries the headers; a plural original is "singular NUL plural" and its
translations are NUL-separated; a context precedes the original with a
0x04 byte.

- const `MAGIC` = `2500072158`

## PluralExpression

`final class Minn\I18n\PluralExpression` · `public/minn/src/Minn/I18n/PluralExpression.php`

The C subset a Plural-Forms header writes its rule in: the number n,
integer literals, parentheses, ! and unary minus, * / %, + -, the four
comparisons, == and !=, && and ||, and the ternary, with C's precedence
and the ternary binding to the right. Parsed into a small tree once and
evaluated per number; nothing is ever handed to PHP to run.

- const `TOKEN` = `'/\\G\\s*(\\d+|n|==|!=|<=|>=|&&|\\|\\||[<>!?:()+\\-*\\/%])/'`
- const `BINARY` = `array (   '||' => 1,   '&&' => 2,   '==' => 3,   '!=' => 3,   '<' => 4,   '>' => 4,   '<=' => 4,   '>=' => 4,   '+' => 5,   '-' => 5,   '*' => 6,   '/' => 6,   '%' => 6, )`
