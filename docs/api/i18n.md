## Catalog

`final readonly class Minn\I18n\Catalog` · `public/minn/src/Minn/I18n/Catalog.php`

One translation file's contents: its headers as written, its messages
keyed the gettext way (the context, a 0x04 byte, then the original; the
original alone without a context), each with its translated forms and,
where the file says, the original plural, and the file's plural rule.
An empty translation counts as none.

## MoFile

`final class Minn\I18n\MoFile` · `public/minn/src/Minn/I18n/MoFile.php`

The GNU gettext binary catalog (.mo), read and written. The file opens
with a magic number that also says its byte order, then a revision, the
message count, and the offsets of two tables of (length, offset) pairs:
the originals, then the translations. The entry with an empty original
carries the headers; a plural original is "singular NUL plural" and its
translations are NUL-separated; a context precedes the original with a
0x04 byte.

- const `MAGIC` = `2500072158`

Used by: `Minn\I18n\TranslationFiles`

### static `read(string $bytes): ?Minn\I18n\Catalog`

The catalog in a .mo file's bytes, or null when they are not one.

### static `write(array $headers, array $entries): string`

A .mo file's bytes for headers and entries, little-endian, entries in
the sorted order gettext expects.

- `@param array<string, string> $headers`
- `@param array<string, array{translations: list<string>, plural: ?string}> $entries`

## PluralExpression

`final class Minn\I18n\PluralExpression` · `public/minn/src/Minn/I18n/PluralExpression.php`

The C subset a Plural-Forms header writes its rule in: the number n,
integer literals, parentheses, ! and unary minus, * / %, + -, the four
comparisons, == and !=, && and ||, and the ternary, with C's precedence
and the ternary binding to the right. Parsed into a small tree once and
evaluated per number; nothing is ever handed to PHP to run.

- const `TOKEN` = `'/\\G\\s*(\\d+|n|==|!=|<=|>=|&&|\\|\\||[<>!?:()+\\-*\\/%])/'`
- const `BINARY` = `array (   '||' => 1,   '&&' => 2,   '==' => 3,   '!=' => 3,   '<' => 4,   '>' => 4,   '<=' => 4,   '>=' => 4,   '+' => 5,   '-' => 5,   '*' => 6,   '/' => 6,   '%' => 6, )`

Used by: `Minn\I18n\PluralRule`

### static `parse(string $expression): ?array`

The expression as a tree, or null when it is not a whole expression.

- `@return array<int, mixed>|null`

### static `evaluate(array $node, int $n): int`

The value of a parsed expression for one number; true is 1 and false 0.

- `@param array<int, mixed> $node`

there; elsewhere on the site, its path from the site root; off the site,

were loaded, and the domains looked for and not found (known, with no
files), all in the order they first appeared, which is the order a locale

domain (and how files there are named), and the domains unloaded for good.
